# YB Tech Business Management

Scaffold aplikasi manajemen bisnis multi-tenant berdasarkan PRD versi 1.0.

## Modul MVP

- Organization dan multi-business
- Authentication dan registrasi employee
- Role Owner, Admin, dan Employee
- Absensi GPS, shift, izin, cuti, lembur, dan koreksi
- Tugas bertingkat dan laporan individual
- Notifikasi, file Cloudinary, laporan, dan audit trail

## Menjalankan proyek

```bash
npm install
npm run dev
```
